# Portafolio web

Sitio personal de una sola página, bilingüe (español/inglés), construido con HTML, CSS y JavaScript puro.

## Archivos
- `index.html`: contenido y secciones.
- `styles.css`: estilos y diseño adaptable.
- `script.js`: selector de idioma y navegación activa.
- `assets/images/`: fotografías e imágenes propias.
- `assets/cv/`: versiones PDF del CV.

## Personalización inicial
1. Busca `TU_CORREO@EJEMPLO.COM` en `index.html` y reemplázalo por tu correo profesional.
2. Cambia el enlace de LinkedIn por la URL de tu perfil.
3. Agrega tus CV como `assets/cv/CV_ES.pdf` y `assets/cv/CV_EN.pdf`.
4. Revisa los textos de experiencia y proyectos para confirmar que describan fielmente tu trabajo.
5. No publiques información confidencial de clientes, empleadores ni equipos.

## Publicar con GitHub Pages
1. Crea un repositorio público llamado `TU-USUARIO.github.io`.
2. Sube el contenido de esta carpeta (no solamente el ZIP).
3. En el repositorio abre **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Selecciona la rama `main` y la carpeta `/ (root)`, y guarda.
6. Espera a que termine la publicación. La dirección será `https://TU-USUARIO.github.io`.

También puedes usar otro nombre de repositorio; en ese caso la URL normalmente será `https://TU-USUARIO.github.io/NOMBRE-REPOSITORIO/`.
